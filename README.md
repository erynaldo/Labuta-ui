  # Iniciando os trabalhos:

  ## Orientações aos integrantes da equipe
  - Instale o Visual Studio Code, Node js e Git no seu computador.
  - Faça o clone do projeto para sua máquina usando o terminal do Git (`git clone https://github.com/erynaldo/Labuta-ui`)
  - Depois de ter clonado o projeto, abra a pasta do projeto no Visual Studio Code.
  - Para concluir as configurações do projeto e rodar ele no navegador, digite no terminal no VS Code os seguintes comandos.

  ## Comandos no terminal do VS Code
  - Execute `npm i` para instalar as dependências do projeto.
  - Execute `npm run dev` para iniciar o servidor de desenvolvimento localmente.

  **Acesse o link do localhost no navegador e veja se o sistema funcionou.**
  - http://localhost:5173/
